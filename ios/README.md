# iPhone app

Open `HealthWatch.xcodeproj` in Xcode, select a development team, and run on an iPhone with Bluetooth enabled. The app targets iOS 17 and uses CoreBluetooth, SwiftUI, Charts, and local JSON storage. No cloud service or HealthKit permission is required.

The dashboard shows the latest BLE snapshot. History stores up to 10,000 minute snapshots (about seven days of continuous connection); time while disconnected is not reconstructed. CSV export includes sensor and PPG quality flags for future diagnosis. Daily step increments are assigned to the iPhone's receipt date. If the watch resets while disconnected, the gap cannot be recovered. SpO2 remains unavailable because the firmware has no validated conversion calibration.

For a short heart-rate test, turn on **Detailed recording** on the Device tab before starting. This stores every one-second BLE snapshot and exports the validity and quality flags. The same 10,000-record limit still applies, so turn it off after the test.

The Xcode project was generated by hand and could not be compiled in this environment because the full Xcode/iOS SDK is absent. Open it in Xcode to perform the first iOS build and signing.
